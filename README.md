# deckthemes-assets
Versioned theme resources and cached Hub previews for Deck Home Themes.

## Community themes

[Blue Glass 1.0.0](https://github.com/Kaal31/deckthemes-assets/releases/tag/blue-glass-v1.0.0) includes a standalone theme ZIP, compressed showcase GIF and poster. Install it with a current experimental ThemeHub build supporting live community pages. The showcase uses sample library data.

Community assets live in `community/<id>/<version>/` with a checksum manifest and source commit. The community publishing workflow validates those checksums and publishes immutable prereleases without changing the existing theme-pack catalogue.
